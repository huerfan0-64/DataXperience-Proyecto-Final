# Proyecto Final DataXperience: Análisis y Predicción de Intervenciones en Salud Pública

## Contexto del Proyecto
Este proyecto aplica el ciclo completo de la Ciencia de Datos (preparación, análisis estadístico descriptivo, visualización y modelado predictivo) sobre un conjunto de datos sintético inspirado en flujos reales de gestión y validación de intervenciones en salud pública en Bogotá, abarcando los entornos **Educativo, Comunitario, Institucional y Laboral**.

El propósito principal es demostrar cómo la automatización en Python permite depurar bases de datos operativas, detectar jornadas atípicas y predecir el alcance poblacional (beneficiarios impactados) a partir del tiempo de gestión y el número de profesionales asignados.
